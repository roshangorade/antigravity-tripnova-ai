Introduction & Background:
The travel industry relies heavily on digital platforms, yet the process of planning a comprehensive trip remains highly fragmented. Users must typically visit multiple platforms to book hotels, check weather, map out routes, and split expenses. TripNova AI is an intelligent, unified travel planning platform that leverages generative AI to create customized itineraries and manage the entire lifecycle of a trip in a single dashboard.

Motivation:
Travelers face decision fatigue when planning trips due to information overload. Existing tools offer generic booking capabilities or basic itinerary mapping but lack end-to-end intelligent personalization and group expense management within a single cohesive workflow.

Target Users:
Solo backpackers, family vacationers, business travelers, and group travelers seeking structured, budget-conscious, and personalized travel experiences.

Project Scope:
The scope includes a full-stack web application with secure authentication, an AI conversational planner (powered by Google Gemini), destination discovery, itinerary persistence, and a user dashboard for tracking trips, bookings, and expenses. External APIs for real-time flights and weather are planned for future integration.

SECTION 2 — PROBLEM STATEMENT

Modern travelers face significant cognitive load and decision fatigue due to the fragmented nature of digital travel tools. To plan a single trip, a user must aggregate data across booking platforms, weather sites, map applications, and expense trackers. Generating a realistic, budget-aligned, and interest-specific itinerary requires hours of manual research. There is a lack of a unified, AI-driven platform that seamlessly combines destination discovery, personalized itinerary generation, and comprehensive trip management (bookings, e-tickets, and expenses) into a single cohesive user experience.

SECTION 5 — RESEARCH GAP

While existing solutions excel in their specific silos, the Research Gap lies in the lack of an integrated, context-aware travel lifecycle platform. Existing systems fail to pass the data context from the "planning/inspiration" phase into the "execution/management" phase. TripNova bridges this gap by unifying AI-driven discovery, structured itinerary persistence, and post-booking management into one continuous workflow, eliminating the need for context-switching.

SECTION 6 — PROPOSED SYSTEM

System Workflow:
1. Discovery: The user browses curated destinations, hotels, and food recommendations.
2. AI Planning: The user inputs trip parameters. The backend interfaces with Gemini AI to generate a structured JSON itinerary.
3. Trip Management: The generated itinerary is saved to the user's dashboard.
4. Execution: The user utilizes the dashboard to manage bookings, upload e-tickets, and track daily expenses.

SECTION 9 — SYSTEM ARCHITECTURE & DATABASE DESIGN

The architecture follows a Full-Stack SPA pattern. The React frontend communicates with the Express backend via REST APIs. The backend handles business logic, proxies requests to Gemini for AI processing, and interfaces with the PostgreSQL database via Drizzle ORM.

Database Entities:
1. users: Stores authentication and profile data. Unique Firebase uid.
2. itineraries: Stores generated trips. Uses jsonb column for flexible nested daily activity data.

SECTION 11 — VIVA PREPARATION (Top Questions)

1. What is your exact research gap?
Ans: Existing platforms handle either transactional booking OR manual planning. None use Generative AI to handle planning and instantly integrate it into a unified expense and booking dashboard.

2. Why use PostgreSQL instead of MongoDB?
Ans: Travel data (users, bookings, payments, trips) is highly relational. ACID compliance is critical for accurate expense tracking and booking management.

3. How does the AI planning work technically?
Ans: The Express backend sends user parameters to the Gemini API with strict system instructions to return structured JSON, not plain text. Express parses this JSON and sends it to React to render the timeline UI.

4. Why use Drizzle ORM instead of Prisma?
Ans: Drizzle provides excellent TypeScript safety, is extremely lightweight, and doesn't require heavy Rust binaries, making our Node backend faster.
